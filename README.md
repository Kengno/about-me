# About Me — animated personal website

Upload `index.html`, `style.css`, and `script.js` to the root of your GitHub repository. All three files must be in the same folder.

GitHub Pages: Repository → Settings → Pages → Deploy from a branch → main → /(root) → Save.

Before publishing: replace `hello@example.com` in `index.html` with your own email, or remove the contact button. Change any personal text you want.

No build tools required. Works as a static website, with scroll reveal, animated hero, marquee, hover effects, and mobile layout. Respects reduced-motion settings.
